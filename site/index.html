Como funciona

Uma ponte no seu computador escuta a live e entrega cada comentário e presente ao jogo aberto no navegador. Você só captura a tela.

Conecte o seu @

Rode a ponte com o seu usuário. Ela reconecta sozinha se a live cair e conta presentes em sequência sem duplicar.

Abra um jogo

Cada jogo é uma página 1080×1920. Nomes, cores e quais presentes fazem o quê ficam num config.json.

Capture e jogue

Fonte Navegador no OBS ou captura de janela no LIVE Studio. A partir daí, quem joga é o chat.

Os jogos

Clique para abrir a demonstração. Em qualquer jogo, a tecla T dispara um evento de teste.

Usar na sua live

Precisa de Node.js 20 ou mais novo, rodando no mesmo computador da transmissão.

# baixar e instalar
git clone https://github.com/Corrar/GameLive
cd GameLive
npm install

# testar sem live (eventos falsos)
npm run simular

# conectar na sua live
npm start -- @seu_usuario

Na transmissão

  • Abra http://localhost:3000/jogos/ e escolha um jogo.
  • OBS: fonte Navegador com a URL do jogo, largura 1080, altura 1920.
  • TikTok LIVE Studio: captura de Janela do navegador com o jogo aberto.
  • Os IDs dos presentes da sua região aparecem em presentes-vistos.json assim que alguém manda um.

O TikTok não tem API oficial para eventos de live: a ponte usa uma biblioteca comunitária que pode parar de funcionar quando o TikTok mudar algo.

Temas políticos em lives com presentes podem violar as regras de monetização do TikTok e, em período eleitoral, a vedação a enquetes do TSE. Os lados de cada jogo são configuráveis para que essa escolha seja do streamer.

GameLive não tem vínculo com TikTok, OBS ou qualquer outra marca citada.
